引擎凭据（不填就不启用该引擎）

下面这些都是可选的。国内网络建议配有道或百度——它们不需要代理， Google / DeepL / Claude / OpenAI 在国内都要走代理。
在「有道智云」控制台创建自然语言翻译服务后获取。
在「百度翻译开放平台」注册通用文本翻译后获取。
改接口地址即可接入其它服务，例如 https://api.deepseek.com/v1、 https://open.bigmodel.cn/api/paas/v4、 http://localhost:11434/v1（Ollama，本地无需 Key）。
自建命令：docker run -d -p 5555:5000 -e LT_LOAD_ONLY=en,zh libretranslate/libretranslate
不要用 5000 端口：macOS 的控制中心（AirPlay 接收器）常驻占用它。
公共实例大多已关闭或需要 Key，建议自建，数据不出内网。
